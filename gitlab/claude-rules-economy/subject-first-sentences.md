# Subject-first sentences

Do not park a fact in a relative clause. Start with the noun, then the verb.
Applies to comments, docs, changelogs, MRs, and chat.

| Do not write | Write |
| --- | --- |
| One the format does not recognize contributes nothing. | Unrecognized formats do not contribute any transcripts. |
| one whose directory cannot be read has none either | An unreadable directory is reported and yields none. |
| directories, for which the listing does not include stat info | A directory listing does not include stat info. |
| Add FLAG, which only requests stat with the listing | Add FLAG to request stat with the listing. |

Banned: `One that…`, `One the…`, `one whose…`, `, for which `. Delete the
relative; if a fact leaves, it was the sentence. The previous sentence is
not an antecedent a comment can rely on.
