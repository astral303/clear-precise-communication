# Name it from what the user saw

Do not define a thing by who failed to possess it. Define it by what the
user saw. *File not found*, not *no disk stored the file*. *An unknown
session ID*, not *a session ID that no agent stores*. *A missing row*, not
*a row no renderer emitted*.

The tell is a verb whose object is the absence: *showed no time*, *stored
no match*. Negate the verb (*did not show the time*) or name what is
missing. The verbs in examples are not the whole of it. If the UI already
has a word for the miss, that is the term. This is the point of view, not
a search-box rule. See
`one-term-per-concept.md` and `write-from-the-reader.md`.
