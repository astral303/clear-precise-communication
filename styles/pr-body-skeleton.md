# Pull request body skeleton

Use this file only when the repository has no pull request or merge request
template. If a template exists, follow that template. Keep its headings.
Do not rename them to the names below.

## Headings

1. **The bug**, or **The change** for a feature: the user-visible problem or
   effect, in the reader's terms.
2. **After this change**: what the user sees now.
3. Cause, then the fix, each under its own noun-phrase heading.
4. **Validation**: two to four lines naming coverage groups. No test names,
   no per-case lines.

The title, the claims, and which details belong are the always-on rules.
This file only names headings for a repository that has not named them.
