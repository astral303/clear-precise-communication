# Subject-first sentences

Start with the noun, then the verb. Do not open with an elided noun and a
relative clause. Applies to comments, docs, changelogs, PRs, and chat.

| Do not write | Write |
| --- | --- |
| One the format does not recognize contributes nothing. | Unrecognized formats do not contribute any transcripts. |
| one whose directory cannot be read has none either | An unreadable directory is reported and yields none. |

Banned openers: `One that…`, `One the…`, `one whose…`. The previous sentence
is not an antecedent a comment can rely on.
