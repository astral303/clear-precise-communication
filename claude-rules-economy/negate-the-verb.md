# Negate the verb, not the object

A negative fact rides the verb or leads the sentence: `didn't find any …`,
`No errors were logged`. Never the postverb `no <noun>` object — "found
no other event" primes "what was found?" and cancels it; "I saw no stars"
briefly reads as "I saw no-stars."

| Do not write | Write |
| --- | --- |
| found no other event | didn't find any other event |
| showed no time | did not show the time |
| returns no rows | didn't return any rows / No rows returned |

`any` is polarity, not padding; `shortest-phrase-that-keeps-the-fact`
does not overrule the early negation — the retraction the shorter form
costs the reader is the spending. Any verb with *no* as its object is
this construction; the scan list is examples. Absences no user
witnessed (logs, tests, internals) are this rule's, not
`name-it-from-what-the-user-saw.md`'s: the fix is mechanical.
