# Setup then point is a tour

A title or opening that walks setup → symptom → twist is a tour. State
the frozen thing the user saw first, then the change. The last sentence
must not be the point.

| Tour (cut) | Point first (write) |
| --- | --- |
| Let repeated runs fill the index instead of reporting the same count | Fix search never indexing new sessions (catch up a couple of seconds before the reply) |
| Until now, … The search indexed nothing itself. | Search never updated the index. … Search now spends a couple of seconds catching up before it answers. |
| … was recognized as an ID, so … although the session was there | An uppercase session ID was reported as not found even though the session exists |

Banned: `Let X` as the title; `Until now`; `instead of` / `although` as
the twist; a "The change" paragraph that is only the old world;
personification (`the corpus outgrew`); diagnostic counts. Mechanism
goes under Cause. See `pr-text-leads-with-the-bug.md`.
